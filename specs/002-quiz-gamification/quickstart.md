# Quickstart & 検証ガイド: ゲーミフィケーション

実装詳細は [plan.md](./plan.md) / [contracts/](./contracts/) 参照。

## 前提・起動

```bash
npm install
npm run dev      # http://localhost:3000
```

学習・クイズのみで検証可能（外部 API キー不要）。

## ユニットテスト（ロジック先行）

```bash
npm run test     # gamification.test.ts を含む
```

期待: `isEffectiveSuccess` / `summarizeSet` のテストが全パス（憲章 原則II：実装前に作成）。
観点は [contracts/gamification-logic.md](./contracts/gamification-logic.md) のテスト表に対応。

## 手動検証シナリオ

### V1. タイムアウトの扱い（US1）

1. 単語帳のクイズ開始画面で**タイム制限モードをオン**（既定15秒）にして開始。
2. 各問にカウントダウンが表示されることを確認。
3. **時間内に正解** → 通常の正解（連続正解が進む）。
4. わざと**時間切れにする** → 問題は自動で進まない（自動スキップ0%）。その後：
   - 正解を選ぶ → UI「正解（時間切れ）」表示、内部は失敗（連続正解リセット・復習キュー追加・セット内再出題）。
   - 誤答を選ぶ → 「不正解（時間切れ）」表示、失敗記録。
5. 管理画面/結果で、時間切れ正解が連続正解数を増やしていないことを確認。

### V2. カウントアップ演出（US2）

1. 任意成績でセット（最大10問）を完了。
2. 結果画面で正解数（実効成功）の**カウントアップ演出**が表示され、**約2秒**で終了することを確認。
3. 終了後すぐに「次の10問へ／ホーム」が操作できることを確認。
4. 成績の良し悪しに関わらず毎回表示されることを確認。

### V3. 全問正解の特別演出（US3）

1. 全問を初回提示で・時間内に正解してセット完了 → 「全問正解おめでとう！」演出が**追加表示**される。
2. 1問でも失敗（誤答 or タイムアウト）したセット → 特別演出は**出ない**（カウントアップのみ）。

### V4. 無制限モードの非退行（US1 裏）

1. タイム制限モードを**オフ**にして学習 → タイマー・タイムアウトなしで従来どおり動作。
2. セット完了時のカウントアップ演出は表示される（タイムアウト概念のみ無効）。

## 完了条件の目安（Success Criteria 対応）

- 自動スキップ発生率0%（V1-4）／時間切れ正解の失敗記録100%（V1-5）。
- 全セットでカウントアップ表示・約2秒終了（V2）。
- 全問正解時のみ特別演出（V3）。
- 無制限モードでリグレッションなし（V4）。
