**Status**: Draft（リバース仕様 / 既存実装からの抽出）

**Input**: 既存プロダクト「AsuMe」の現状の振る舞いを、全体で1つの仕様書としてリバース仕様化したもの。出典は `CLAUDE.md` と実コード。

## Overview

AsuMe は、TOEIC（ビジネス・旅行・フォーマル）向けの英単語を、4択クイズと穴埋め文脈で反復学習するための個人用ワード学習アプリである。学習データは利用者のデバイス内に保存され、サーバーやアカウント登録を必要としない。利用者は自分で用意した単語リスト（CSV）を取り込むか、英単語を入力するだけで例文・訳・発音・品詞を自動生成して単語帳（プロジェクト）を作り、学習履歴に基づいて出題が最適化されるクイズで「殿堂入り（マスター）」を目指す。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 単語帳を取り込んで4択クイズで学習する (Priority: P1)

利用者は手持ちの単語リスト（CSV）を取り込んで単語帳を作り、4択クイズで反復学習する。これがアプリの中核ループであり、これ単体で価値が成立する MVP。

**Why this priority**: 取り込み→出題→採点の基本ループがなければアプリとして成立しない。最も重要。

**Independent Test**: 有効な CSV を1つ取り込み、クイズを開始して10問程度を解き、間違えた問題が同セット内で再出題され、最後に結果が表示されることを確認すれば単独で検証できる。

**Acceptance Scenarios**:

1. **Given** `words`・`japanese` を含む有効な CSV、**When** それをアップロードする、**Then** 単語帳（プロジェクト）が作成され学習を開始できる。
2. **Given** ある単語帳、**When** クイズを開始する、**Then** 単語帳内の他単語からダミー3つを混ぜた4択問題が、最大10問のセットとして出題される。
3. **Given** 出題中に問題を間違える、**When** その1セットを進める、**Then** 間違えた問題は同セット内で正解するまでキュー末尾に再追加され繰り返し出題される。
4. **Given** 1セット（最大10問）を解き終える、**When** 最後の問題に回答する、**Then** 結果画面に遷移し成績が表示される。
5. **Given** 出題中の単語、**When** 読み上げを要求する、**Then** 単語（活用形を含む）が正しい英語の発音で読み上げられる。

### User Story 2 - 学習履歴に基づく出題最適化と殿堂入り (Priority: P2)

学習を重ねるほど、未回答・正答率の低い単語が優先的に出題され、確実に覚えた単語は出題対象から外れて学習効率が上がる。

**Why this priority**: 単なるランダム出題より定着効率が大きく上がり、リピート学習の価値の核。

**Independent Test**: 同じ単語帳を複数セット学習し、ある単語を3回連続正解させると以降の通常出題に現れなくなること、未回答・低正答率の単語が優先されることを確認すれば検証できる。

**Acceptance Scenarios**:

1. **Given** ある単語を3回連続で正解する、**When** 次の出題を選定する、**Then** その単語は「殿堂入り」となり通常学習の出題対象から除外される。
2. **Given** 未回答または正答率の低い単語が存在する、**When** 次セットを生成する、**Then** それらが優先的に選ばれる。
3. **Given** 直近で間違えた単語がある、**When** 「復習」を選ぶ、**Then** 直近の誤答単語を集中的に出題する特訓モードが始まる。
4. **Given** 全単語を最低1回は解いた、**When** 周回が完了する、**Then** 1周として扱われる。

### User Story 3 - 英単語だけ入力して単語データを自動生成 (Priority: P3)

利用者は英単語だけを入力すれば、TOEIC 文脈に沿った日本語訳・例文・発音記号・品詞を含む完全な単語データが自動生成され、単語帳を素早く作れる。

**Why this priority**: CSV を自前で用意する手間を排し、単語入力だけで学習を始められるようにする差別化機能。

**Independent Test**: 英単語を数件入力して生成を実行し、各単語に訳・例文（対象語が空欄化されている）・発音・品詞が付与され、進捗が逐次表示されることを確認すれば検証できる。

**Acceptance Scenarios**:

1. **Given** 英単語のリスト、**When** 自動生成を実行する、**Then** 1単語ずつ処理され、進捗バーと生成結果プレビューがリアルタイムに更新される。
2. **Given** 複数の意味を持つ単語（例: book, record）、**When** 生成する、**Then** TOEIC で最も出題されやすい意味と品詞が選ばれ、品詞に整合する形式の訳（動詞なら「〜する」等）が付与される。
3. **Given** 生成された例文、**When** 単語データを保存する、**Then** 例文中の対象語は空欄化され、活用形（例: attempted）も検知して空欄化されたうえで、表示と読み上げが両立する形で保持される。
4. **Given** 「英単語・意味・品詞」だけを入力して部分補完（Enrich）を実行する、**When** 補完する、**Then** 例文と発音記号のみが文脈に沿って自動生成される。

### User Story 4 - 単語帳の管理と不足データの補完 (Priority: P3)

利用者は管理画面で成績を確認し、単語の追加・修正・削除、殿堂入りのリセット、単語帳名の変更を行い、空欄の多い単語帳を一括補完できる。

**Why this priority**: 取り込んだデータの品質を整え、長期運用を可能にする。学習体験の継続に寄与する。

**Independent Test**: 管理画面で単語を1件削除・1件追加・名称変更し、訳や例文が空欄の単語帳に対して一括補完を実行して空欄が埋まることを確認すれば検証できる。

**Acceptance Scenarios**:

1. **Given** ある単語帳の管理画面、**When** 単語の削除/追加/修正、殿堂入りリセット、名称のインライン変更を行う、**Then** 変更が即座に保存・反映される。
2. **Given** 訳や例文が空欄の単語を含む単語帳、**When** 一括補完バナーから補完を実行する、**Then** 未補完の全単語に対し補完処理が順次実行され、空欄が埋まる。

### User Story 5 - データのバックアップと復元・書き出し (Priority: P3)

利用者は学習データと進捗を ZIP でバックアップ／復元でき、単語データを CSV としても書き出せる。

**Why this priority**: ローカル保存のためデバイス紛失やブラウザデータ消去で失われるリスクがあり、移行・保全手段が必要。

**Independent Test**: 単語帳を ZIP にエクスポートし、データを消した状態でインポートして元の単語と進捗が復元されること、CSV エクスポートが文字化けせず開けることを確認すれば検証できる。

**Acceptance Scenarios**:

1. **Given** 学習中の単語帳、**When** ZIP エクスポートする、**Then** 単語データと学習進捗を含むバックアップファイルが得られる。
2. **Given** バックアップ ZIP、**When** インポート（復元）する、**Then** 単語と進捗が復元される。
3. **Given** ある単語帳、**When** CSV エクスポートする、**Then** 表計算ソフトで文字化けせず開ける CSV が得られる。

### Edge Cases

- `words` 列が無い、または単語が空文字の行は取り込み時に自動除外される。有効な単語が1件も無い場合はエラーを表示する。
- `japanese`（訳）が空欄の単語が含まれる場合、取り込み成功直後に「管理画面から一括補完を実行してください」と警告を表示する。
- 1セット（最大10問）終了直後の再描画で存在しない問題インデックスを参照しても、安全に結果画面へ遷移する（配列外参照で破綻しない）。
- 自動生成系の処理中に本日の API 利用上限に達した場合、一括補完などのループは直ちに安全に中断し、上限到達メッセージを表示する。
- 自動生成で外部から発音記号が取得できない場合は、フォールバック手段で発音記号を補う。
- 名詞・動詞で発音が変わる単語（record, project 等）は、判定された品詞に整合する発音記号が割り当てられる。

## Requirements *(mandatory)*

### Functional Requirements

**学習データとプロジェクト**
- **FR-001**: System MUST すべての学習データ（単語帳・単語・進捗）を利用者のデバイス内に永続化し、ブラウザを閉じても保持する。アカウント登録やサーバー送信を必須としない。
- **FR-002**: System MUST 複数の単語（QuestionData）をまとめた単語帳（Project）単位でデータを管理し、各単語帳ごとに誤答記録を保持する。

**取り込み（CSV）とバリデーション**
- **FR-003**: Users MUST be able to `paragraphs`/`words`/`japanese`（必須）と `phonetic`/`partOfSpeech`（任意）の列を持つ CSV を取り込んで単語帳を作成できる。
- **FR-004**: System MUST 取り込み時に `words` が無い/空の行を自動除外し、有効な単語が0件ならエラー表示する。`japanese` 空欄の単語があれば一括補完を促す警告を表示する。

**クイズエンジン**
- **FR-005**: System MUST 4択問題のダミー（不正解）3つを、同じ単語帳内の他単語からランダム抽出して生成する。
- **FR-006**: System MUST 1セットを最大10問とし、ランダム抽出した問題を出題する。
- **FR-007**: System MUST 同セット内で間違えた問題を、正解するまでキュー末尾に再追加して繰り返し出題する。
- **FR-008**: System MUST 単語（活用形を含む）を正しい英語発音で読み上げできる。
- **FR-009**: System MUST 1セット完了時、存在しない問題インデックス参照でも破綻せず結果画面へ遷移する。

**出題アルゴリズムと習熟管理**
- **FR-010**: System MUST 各単語の正答数・誤答数・連続正解数・殿堂入り状態・最終学習日時を記録する。
- **FR-011**: System MUST 3回連続正解した単語を殿堂入りとし、通常学習の出題対象から除外する。
- **FR-012**: System MUST 殿堂入りを除外したうえで、未回答および正答率の低い単語を優先的に出題する。
- **FR-013**: Users MUST be able to 直近で間違えた単語を集中出題する復習モードを利用できる。
- **FR-014**: System MUST 全単語を最低1回解いた状態を1周として扱う。

**単語データ自動生成（CSV Generator / Enrich）**
- **FR-015**: Users MUST be able to 英単語のみの入力から、TOEIC 文脈に沿った訳・例文・発音記号・品詞を含む完全な単語データを自動生成できる。
- **FR-016**: System MUST 一括生成時、サーバータイムアウトを避けるため1単語ずつ処理し、進捗バーと結果プレビューをリアルタイム表示する。
- **FR-017**: System MUST 複数意味を持つ単語について、TOEIC で最も出題されやすい意味・品詞を選び、品詞に整合する形式の訳を付与する。
- **FR-018**: System MUST 名詞・動詞等で発音が異なる単語に、判定品詞に整合する発音記号を割り当てる。発音記号が取得できない場合はフォールバックで補う。
- **FR-019**: System MUST 例文中の対象語を空欄化する際、活用形も検知して空欄化し、画面表示では正解を隠しつつ読み上げでは正しい英語として発音できる形でデータを保持する。
- **FR-020**: Users MUST be able to 「英単語・意味・品詞」だけの入力で、例文と発音記号のみを部分補完（Enrich）できる。
- **FR-021**: Users MUST be able to 訳や例文が空欄の単語を含む単語帳に対し、未補完の全単語を順次一括補完（Batch Enrich）できる。

**単語帳の管理**
- **FR-022**: Users MUST be able to 管理画面で成績確認、単語の個別追加・修正・削除、殿堂入りのリセット、単語帳名のインライン変更を行える。

**継続学習 UX**
- **FR-023**: System MUST 結果画面で未習得の単語が残る場合、学習開始画面を介さず次の最大10問へ進める固定フッターのボタンを表示する。

**バックアップ・書き出し**
- **FR-024**: Users MUST be able to 単語帳のデータと進捗を ZIP としてエクスポート（バックアップ）し、ZIP からインポート（復元）できる。
- **FR-025**: Users MUST be able to 単語データを、表計算ソフトで文字化けしない CSV として書き出せる。

**利用上限保護**
- **FR-026**: System MUST 外部 API への過剰アクセスを防ぐため、アプリ全体で1日あたりの上限（既定: 2450回）および 1 利用者（IP）あたりの上限（既定: 200回/日）を設ける。
- **FR-027**: System MUST 上限到達時、自動生成・一括補完などのループ処理を直ちに安全に中断し、本日の利用上限に達した旨のメッセージを表示する。

### Key Entities *(include if feature involves data)*

- **QuestionData（単語）**: 1単語の学習データ。英単語、日本語訳、穴埋め用英文（空欄は `_`、活用形は表示と読み上げを両立する形式で保持）、発音記号、品詞、および学習履歴（正答数・誤答数・連続正解数・殿堂入り状態・最終学習日時）を持つ。
- **Project（単語帳）**: 複数の QuestionData を束ねる学習単位。単語帳名と、誤答単語の記録（復習モード用）を持つ。
- **学習セット（Quiz Set）**: 1回の学習で出題される最大10問のまとまり。誤答はセット内で正解するまで再出題される。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 利用者は有効な単語リストを取り込んでから1分以内に最初のクイズを開始できる。
- **SC-002**: 1セットは最大10問で構成され、誤答した問題は同一セット内で正解するまで100%再出題される。
- **SC-003**: ある単語を3回連続正解すると、それ以降その単語は通常学習の出題に現れない（殿堂入り除外率100%）。
- **SC-004**: 英単語のみの入力から、訳・例文・発音・品詞がすべて埋まった単語データが生成される（生成成功時の必須項目充足率100%）。
- **SC-005**: 学習結果画面から1操作で次のセットへ継続でき、学習開始画面を経由しない。
- **SC-006**: 利用上限到達時、進行中のループ処理は追加リクエストを発行せず中断し、利用者に上限到達が明示される。
- **SC-007**: ブラウザを閉じても学習データと進捗が保持され、エクスポートした ZIP からインポートすると単語と進捗が復元される。
- **SC-008**: 書き出した CSV を一般的な表計算ソフトで開いても日本語が文字化けしない。

## Assumptions

- 本書は新規機能ではなく、既存プロダクト「AsuMe」の現状を `CLAUDE.md` と実コードから抽出したリバース仕様である。実装の詳細（フレームワーク、利用 API、ライブラリ、保存方式など）は `CLAUDE.md` に記載があり、本書はその挙動を利用者価値の観点でまとめている。
- 単一利用者・単一デバイス利用を前提とし、複数端末間の自動同期は範囲外（ZIP の手動エクスポート/インポートで移行する）。
- 自動生成系の機能は外部 API への接続が前提であり、未設定・失敗時はフォールバックまたは一括補完の案内で運用を補う。
- 利用上限の既定値（全体2450回/日・IP 200回/日）は無料枠保護のための初期設定であり、運用に応じて調整され得る。
- 学習対象の主用途は TOEIC（ビジネス・旅行・フォーマル）向け語彙であることを前提に、意味選定・例文生成が最適化されている。
