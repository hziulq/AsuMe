# 単語データ自動生成 (Enrich) の仕様
エージェントが単語データの自動生成・補完（Enrich）機能を修正・追加する際は、以下の仕様と処理フローを遵守してください。

## 1. 役割と使用API
- **WordsAPI**: 英単語の意味リスト、品詞、および発音記号オブジェクト（品詞別の発音）の取得。
- **CMU Pronouncing Dictionary (npm)**: WordsAPIで発音記号が取れなかった場合のフォールバック（ARPAbet形式・小文字化）。
- **OpenAI API (gpt-4o-mini)**: 意味の選定、日本語訳、例文の生成の中核。
- **翻訳API (DeepL)**: OpenAIのAPIキー未設定、または生成失敗時のフォールバック。

## 2. 自動生成のロジック
- **TOEIC特化の文脈判断**: WordsAPIから得た複数の意味リストをOpenAIに渡し、TOEIC（ビジネス、オフィス、旅行、フォーマル）で最も頻出する意味と品詞を推論させます（JSONモードを利用）。
- **品詞に基づく翻訳の厳格化**: プロンプト制約により、動詞なら「〜する」といった形で、品詞と日本語訳の形式が確実に一致するように生成させます。
- **品詞に基づく発音記号の最適化**: WordsAPIから取得した発音記号オブジェクトと、OpenAIが推論した品詞をマッチングさせ、名詞・動詞で発音が変わる単語（例: record）にも正確な発音記号を設定します。
- **穴埋め例文の置換**: 例文中の対象単語を自動で空欄に置換します。過去形等の活用形も検知し、学習時のヒントと音声読み上げ（TTS）の両立のため、内部的には `_[活用形:元の活用語]` の形式（例: `_[活用形:attempted]`）で置換・保存します。

## 3. アプリケーション上での補完フロー
- **一部データの補完生成 (Enrich)**: クイズ結果画面からのインライン編集や管理画面の手動追加時、英単語・意味・品詞から「例文と発音記号のみ」をワンボタンで自動生成する機能 (`/api/enrich`) 。
- **不足データの一括補完 (Batch Enrich)**: 日本語訳や例文が空欄のままのCSVデータを取り込んだ際、管理画面の上部に一括補完バナーが表示され、クリックするだけで未補完の全単語に対して自動生成処理をシーケンシャルに実行できます。
  - ※大量の単語を一括生成する際は、サーバーのタイムアウトを防ぐためフロントエンドから1単語ずつAPIを呼び出し、リアルタイムでプログレスバーを表示します。
  - ※429 Too Many Requests等のレート制限エラーが発生した場合は、ループを安全に中断しエラーメッセージを表示します。
