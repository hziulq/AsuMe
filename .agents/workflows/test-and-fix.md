# ワークフロー: テスト実行とエラー自動修正 (/test-and-fix)
このワークフローは、プロジェクトのテストを起動し、エラーが検出された場合に自動で原因分析および修正を行うための手順です。

## 実行手順
1. ターミナルで Jest テストを実行します：
   ```powershell
   npm run test
   ```
2. テストがすべて成功した場合：
   - ユーザーにテスト結果（パスした件数など）を報告し、完了します。
3. テストが失敗した場合：
   - 失敗したテストのログおよびエラー箇所を精査します。
   - 関連するコード（`src/lib/*.ts` など）を読み込み、バグの原因を特定します。
   - バグを修正するためのコード変更を行います（※テンプレートリテラルのエスケープルールなどの既存の `rules` に違反しないよう注意してください）。
   - 修正後、再度 `npm run test` を実行して確認します。
   - すべてのテストが成功するまでこのサイクルを繰り返します。
