# ワークフロー: プロジェクトのビルド検証とコンパイルエラー修正 (/verify-build)
このワークフローは、Next.js アプリケーションが正常にビルドできるか検証し、TypeScriptやコンパイルのエラーを自動修正するための手順です。

## 実行手順
1. ターミナルでプロダクションビルドを実行します：
   ```powershell
   npm run build
   ```
2. ビルドが成功した場合：
   - 「ビルドは正常に完了しました」とユーザーに報告し、完了します。
3. ビルドが失敗した場合（TypeScriptエラーやコンパイルエラー）：
   - エラーログから、問題が発生しているファイルと行数、エラー原因を特定します。
   - 該当箇所を修正します。特に `any` 型のエラー（ESLint）や、テンプレートリテラルでバックスラッシュがエスケープされているエラーがないか確認してください。
   - 修正後、再度 `npm run build` を実行して確認します。
   - ビルドが完全に通るまでこのサイクルを繰り返します。
